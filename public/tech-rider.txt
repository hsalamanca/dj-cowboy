DJ COWBOY — TECH RIDER (CLUB / STAGE)
=====================================

SET LENGTH
----------
60–120 minutes standard. Confirm open-to-close separately.

BOOTH
-----
- Stable DJ booth with clear sightlines to the dancefloor
- CDJ-3000 / CDJ-2000NXS2 x2 (or equivalent) + DJM-900NXS2 / DJM-A9
- OR: Pioneer XDJ-XZ / equivalent all-in-one (confirm in advance)
- USB inputs available; Serato/rekordbox USB playback preferred
- Booth monitors at ear level; clean power

HOSPITALITY
-----------
- Water at booth
- Secure bag storage
- Guest list: +2

LOAD-IN
-------
- Access 60–90 minutes before set time
- On-site contact name + number day-of

TRAVEL / HOTEL
--------------

- Overnight stay required for load-out after 1:00 AM outside metro

LIGHTING / VISUALS
------------------

- If brand visuals required, send assets 72h prior
